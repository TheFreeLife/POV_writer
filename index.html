📖 동작 코드(JavaScript) 사용 설명서

1. 입력 변수 접근 (input)

노드에 정의된 모든 입력 항목(수치, 텍스트, Input 포트 핀)은 input.변수명 으로 접근할 수 있습니다.
예: input.체력, input.이름, input.상위데이터

2. 출력 반환 (return 객체)

반드시 return { output핀이름: 값, ... } 형태로 객체를 반환해야 합니다.
이름 매칭 방식: return 객체의 키(Key) 이름과 Output 포트 핀 이름이 정확히 일치해야 합니다.

💡 단축 표기법 vs 풀어서 쓰기 
// 1) 단축 표기법 (변수명이 핀 이름과 같을 때)
const 프로필 = input.이름 + ' / ' + input.직업;
const 전투력 = input.공격력 * 2;
return { 프로필, 전투력 };

// 2) 풀어서 쓰기 (키 이름 = output 핀 이름)
return {
  프로필: input.이름 + ' / ' + input.직업,
  전투력: input.공격력 * 2
};

3. 다양한 사용 예시

🔹 예시 A. 텍스트 가공 및 결합 
const 결과 = `📌 [${input.제목}]\n• 작가: ${input.작가}\n• 내용: ${input.본문}`;
return { 결과 };
🔹 예시 B. 수치 계산 및 조건문 
const 총합 = input.근력 + input.민첩 + input.지능;
const 랭크 = 총합 >= 100 ? 'S랭크' : 'A랭크';
return { 총합, 랭크 };
🔹 예시 C. 코드가 없는 경우 (데이터 보관 노드)

동작 코드를 작성하지 않으면, 입력받은 값이 이름이 같은 Output 핀으로 자동 전달됩니다.
